# 冻结版本的新任务对照

[完整英文记录](heldout-2026-10-11.md)

冻结当前 Adaptive Workflow 后，用两个未参与其设计的真实源码问题进行了 12 次全新会话对照。**三种配置均通过了四次任务验收。本轮没有得到质量优势，也没有达到预登记的重复成本收益标准。**

## 任务与准备

一个任务来自 LessonPilot 的教学资料图片投影模块：错误的 Markdown 围栏可能让代码示例中的图片被重写，替换地址也可能误改说明文字。另一个来自 [名笺](https://github.com/sky-k111/ai-name) 的响应解析服务：部分错误结构泄漏内部异常，合法 JSON 中的中文引号被改写。原源码未植入缺陷，修复在独立副本中进行。

评估者在运行前写明修复范围和完整验收要求。Markdown 的顶层围栏规则参考 [CommonMark 0.31.2](https://spec.commonmark.org/0.31.2/#fenced-code-blocks)，仍保留原有图片语法和处理范围；名笺要求统一五个操作的错误边界、保留字符串和合法附加字段，检查结构、重复键、数值和多对象歧义。没有测试生产环境或完整应用。

Markdown 原有 11 项测试通过，固定外部验收为 7/19。名笺没有发现原项目的 Python 测试，本轮提供的 8 项可见兼容检查通过，固定外部验收为 8/55。分别编写的校准修复通过 19/19、55/55 及所有可见检查，确认任务可完成。

先完成全部 12 个副本、哈希检查和独立 Git 索引，再运行任何基线测试。每个副本初始索引均不含生成缓存，避免了上轮复制与测试重叠的问题。共享的已安装依赖和服务端缓存仍未隔离，因此不能宣称全环境无缓存。

## 对照与结果

两项任务各重复两次，比较无可选流程 Skill、正常使用同一批 13 个流程 Skill、同一技能库加明确调用的 Adaptive Workflow。普通技能库没有被要求强行规划。所有会话使用 gpt-6.1-sol、high 和 CLI 0.162.0，每次上限 720 秒。测量版本为 `d3413226187fd9944c5eec31e95a5f09bb6024e2`；期间未改 Skill、提示、验收或任务，也没有替换或重跑结果。

预登记的明显质量信号要求 Adaptive 四次全部通过，且两个对照各最多通过一次；该小样本标准也不等于统计显著或普遍优势。重复成本信号要求同一任务双方两次均通过，且 Adaptive 两次未缓存输入都至少少 30%。两个标准均未达到。

审计确认实际模型设置一致，被测 Skill 的全部资源未改，没有混入个人自适应全局规则或父项目接入指令；临时凭据均已删除。各组新增测试数量不同，不能用数量代替覆盖质量。默认组同样自主完成调查、回归和复核，这些行为不能当成 Skill 独有能力。

## 局限与项目取舍

这是由评估者选择并明确契约的两个模块修复，任务虽未参与 Skill 设计，验收仍由同一作者编写。它不是完全盲测、随机生产抽样或整个复杂项目的交付实验。每项只有两次，明确调用也不能证明安装后自动生效。缓存未控制，并发时间仅作记录，不能推导实际费用、严格成本因果或速度优势。

CLI 会自动记录项目目录的信任状态，模型及执行设置没有变化；实际配置在结束后留档。实时读取器将工具输出中的 Unicode 行分隔符拆成了碎片，审计重组了相关命令和状态，完整原生记录仍保留；重组文本不能冒充原始逐字输出。本轮没有追加事后验收，没有把自查发现的新用例改算为独立优势。

这些负结果说明，当前不能以“普遍优于默认 Codex”为目标继续堆通用规则。项目应保留实验性定位。后续若重新设计，应围绕模型缺少的具体项目知识、可执行证据检查或操作约束提出可失败的假设，再验证增量价值；这些方向目前只是建议，不是已证明的解决方案。

完整原始材料、冻结版本、验收、审计和修复补丁保留在本地。实验没有覆盖原项目工作区，也没有将行为副本、私人配置或第三方 Skill 副本随仓库分发。[之前的归档实验](real-project-2026-10-11.zh-CN.md)和[合成实验](benchmark-2026-10-11.zh-CN.md)继续保留。
